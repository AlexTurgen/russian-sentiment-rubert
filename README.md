# Классификация тональности русскоязычных отзывов (дообучение rubert-tiny2)

Лабораторная работа №2 по курсу «Интеллектуальные нейросетевые системы» (тема: обучение языковой модели для текстов на русском языке).

Языковая модель `cointegrated/rubert-tiny2` дообучена на отзывах КиноПоиска для классификации тональности на три класса: **negative / neutral / positive**.

## Датасет

Источник: [`blinoff/kinopoisk`](https://huggingface.co/datasets/blinoff/kinopoisk) (Hugging Face, лицензия MIT), около 36,6 тыс. отзывов. Метка `grade3` (Bad / Neutral / Good) получена по оценке автора отзыва.

Предобработка:
1. удалены пропуски и дубликаты, оставлены тексты длиной от 20 до 3000 символов;
2. классы сильно несбалансированы (положительных отзывов около 75%), поэтому применено сокращение положительного класса (undersampling) до 5000 примеров;
3. разбиение на train / val / test в пропорции 80 / 10 / 10 со стратификацией по классам.

| Класс | До балансировки | После балансировки |
|---|---|---|
| positive | 22 527 | 5 000 |
| negative | 3 881 | 3 881 |
| neutral | 3 880 | 3 880 |

Размеры выборок: train 10 208, val 1 276, test 1 277. Файлы лежат в папке `data/`.

## Модель и обучение

- Базовая модель: `cointegrated/rubert-tiny2` (компактная русскоязычная модель класса BERT, подходит для быстрого дообучения на бесплатной GPU).
- Дообучение: `Trainer` из библиотеки Hugging Face Transformers, 3 эпохи, learning rate 3e-5, batch size 32, weight decay 0,01, максимальная длина 256 токенов.
- Лучшая эпоха выбиралась по macro-F1 на валидации.
- Среда: Google Colab, GPU T4. Обучение заняло около 2 минут.

## Результаты на тестовой выборке

| Accuracy | Precision (macro) | Recall (macro) | F1 (macro) |
|---|---|---|---|
| 0,689 | 0,663 | 0,675 | 0,655 |

| Класс | Precision | Recall | F1 | Объектов |
|---|---|---|---|---|
| negative | 0,67 | 0,86 | 0,75 | 389 |
| neutral | 0,56 | 0,33 | 0,41 | 388 |
| positive | 0,76 | 0,83 | 0,80 | 500 |

Матрица ошибок (строки: истинный класс, столбцы: предсказанный):

| | negative | neutral | positive |
|---|---|---|---|
| **negative** | 335 | 42 | 12 |
| **neutral** | 143 | 128 | 117 |
| **positive** | 24 | 59 | 417 |

Нейтральный класс распознаётся хуже всего: граница между «нормально» и «скорее хорошо / скорее плохо» размыта, а метки получены автоматически по оценке автора.

## Классификация пяти примеров

Тексты не входят в обучающую выборку. Запуск: `python src/predict.py --model model`.

| № | Текст | Ожидаемый | Предсказание | Уверенность |
|---|---|---|---|---|
| 1 | Потрясающий фильм! Сильный сюжет, отличная игра актёров, смотрел не отрываясь. | positive | neutral (positive 0,47) | 48,6% |
| 2 | Ужасное кино: скучный сюжет, пустые диалоги, два часа потраченного времени. | negative | negative | 66,9% |
| 3 | Фильм неплохой, но ничего особенного. Один раз посмотреть можно. | neutral | neutral | 63,4% |
| 4 | Ну, такое. | neutral | neutral (negative 0,42) | 42,5% |
| 5 | Отличный фильм, если вы всегда мечтали выспаться в кинотеатре. | negative (сарказм) | positive | 61,9% |

Выводы: явный негатив и смешанную оценку модель определяет верно. Ошибки связаны с размытым нейтральным классом (пример 1), нехваткой контекста в сверхкоротком тексте (пример 4) и сарказмом, который модель не распознаёт (пример 5).

## Запуск

```bash
pip install -r requirements.txt
python src/predict.py --model model                      # 5 примеров
python src/predict.py --model model --text "Ваш отзыв"   # свой текст
```

Веса модели хранятся через Git LFS (`model/model.safetensors`), поэтому перед клонированием установите Git LFS (`git lfs install`).

## Ограничения

- Метки нейтрального класса шумные, поэтому его качество низкое.
- Положительный класс сокращён до 5000 примеров, часть данных не использована.
- Модель обучена только на отзывах о фильмах и может хуже работать на других доменах.
- Модель не распознаёт сарказм.
- Обучение было коротким (3 эпохи); более длинное обучение или более крупная модель могут улучшить результат.
